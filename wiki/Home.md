# ANGONUEVE

**ANGONUEVE** é uma plataforma angolana de tecnologia que oferece serviços digitais: criação de sites profissionais, alojamento web, assistência técnica, IA generativa e muito mais.

## Funcionalidades Principais

- **Criação de Sites com IA** — Gere sites completos com HTML/CSS/JS através de inteligência artificial (Gemini 2.5 Flash)
- **Modelos de Sites** — Marketplace com templates pré-construídos
- **Chatbot Inteligente** — Suporte ao cliente com IA
- **Área de Cliente** — Gestão de serviços, facturas e pagamentos
- **Painel Admin** — CRM completo com gestão de clientes, funcionários, encomendas, facturas e conteúdos
- **Sistema de Funcionários** — Dashboard com permissões por papel
- **Equipa** — Secção de equipa com visibilidade apenas para admin

## Stack Tecnológica

| Camada | Tecnologia |
|---|---|
| Frontend | HTML5, CSS3, JavaScript (vanilla) |
| Backend | PHP 8.x |
| Base de Dados | MariaDB/MySQL |
| IA | Google Gemini 2.5 Flash API |
| Ícones | Font Awesome 6 |
| Mapas | Leaflet.js |
